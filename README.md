# 📚 14 Kitab Klubu

**14 Kitab Klubu** — kitab sevərləri bir araya gətirən, oxucu icması yaratmaq, ikinci əl kitab mübadiləsi və paylaşımları etmək üçün hazırlanmış C# .NET Core MVC veb-tətbiqidir.

## 🚀 Texnologiyalar
* **Backend:** C#, .NET Core (ASP.NET Core MVC)
* **Database:** SQLite
* **Frontend:** HTML5, CSS3, Bootstrap
* **Version Control:** Git & GitHub

## ✨ Xüsusiyyətlər
* Admin və İstifadəçi panellərinin ayrılması
* Təhlükəsiz şifrələmə mexanizmi (`PasswordHelper`)
* SQLite verilənlər bazası inteqrasiyası
